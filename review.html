Meta 應用程式審查說明

本頁供審查人員理解實際用途與現階段可測試範圍，不是已完成的 OAuth 或搜尋操作介面。

應用程式功能

TRPG Public Monitor 為唯讀的公開 TRPG 社群觀測工具。計畫透過 threads_basic 確認授權身分，申請 threads_keyword_search 搜尋公開貼文，例如「TRPG」、「跑團」、「桌上角色扮演」。預計保留必要的貼文文字、發文時間、原始網址，供事件分類、去重與趨勢摘要。

資料使用與安全

  • 不代表使用者發布貼文、留言或追蹤他人。
  • 只在授權範圍內存取公開內容，不嘗試繞過非公開權限。
  • Token 僅保存在受限制的伺服器環境中，不展示於本網站。
  • 資料來源不可讀時明確標示，而不宣稱該議題無人討論。
  • 參考隱私權政策與資料刪除說明。

目前測試限制

本站目前是資訊介紹頁，並不提供可操作的 Threads OAuth 或關鍵字搜尋功能。尚未經 Meta 審查核准進階公開搜尋權限；不會以模擬資料或其他平台貼文冒充 Threads API 實測結果。

正式送審前所需材料

  1. 有效網站及公開隱私政策、資料刪除聯絡管道。
  2. 依 Meta 指示提供可測試的授權與搜尋功能，或獲准的替代測試方法。
  3. 操作影片、實際權限用途說明、資料處理問卷及必要驗證。
