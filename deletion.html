DATA DELETION

資料查詢與刪除

如希望查詢、更正或刪除本計畫保存的特定公開社群內容，可以使用以下管道聯繫專案管理者。

一、提出請求

請寄至：CONTACT_EMAIL_REPLACE_ME。

目前仍待管理者提供能接收郵件的公開聯絡信箱；正式提交 Meta 審查前必須補齊。

郵件主旨建議為「TRPG Public Monitor 資料刪除請求」，內文盡可能提供：

  1. 希望查詢、更正或刪除的公開貼文網址。
  2. 希望處理的資料範圍與理由。
  3. 供管理者回覆的信箱。

請勿主動提供身份證字號、密碼、Access Token 或其他不必要的敏感資料。

二、處理方式

收到請求後，管理者會核對索引位置與需處理範圍；若有必要，才要求最低限度的合理確認。將依適用法律、平台政策與研究必要性處理並回覆。此計畫無法代替原平台刪除他人發布的原文。

三、取消 Threads 授權

未來若你曾授權本應用程式，可在 Threads／Meta 的網站權限管理介面撤銷授權；管理者應停止使用對應憑證，並按政策刪除不應繼續保留的資料。本展示網站目前沒有 OAuth 登入功能。

四、版本歷史與備份

部分資料可能保留在 GitHub 版本歷史、備份或已生成的報告中。管理者會在合理可控制的範圍內處理副本；第三方服務自身的保存期限則依該服務的政策。

Please use the designated contact email for data requests. Do not post personal identification or sensitive information in public issue discussions.
